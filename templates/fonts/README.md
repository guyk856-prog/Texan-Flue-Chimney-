# Vendored PDF fonts

These actual local TTF files are embedded by the PDF worker as data URLs. Runtime rendering makes no font-network request. Both fonts are distributed under the SIL Open Font License; unmodified license texts are alongside them.

Sources from the Google Fonts source repository:

- `https://github.com/google/fonts/tree/main/ofl/librebaskerville` — `LibreBaskerville[wght].ttf` saved as LibreBaskerville.ttf.
- `https://github.com/google/fonts/tree/main/ofl/sourcesans3` — `SourceSans3[wght].ttf` saved as SourceSans3.ttf.
